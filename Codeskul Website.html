SkulMaster EMIS — Built for Sierra Leonean Schools

A complete, offline-first school management ecosystem combining a high-speed C# .NET Windows desktop engine with a zero-data mobile web portal for teachers.

C# .NET 10 • WinForms • SQLCipher AES-256

100% Operational Without Internet Connectivity

Designed specifically for Pre-School, Primary, JSS, and SSS institutions (Science, Arts, and Commerce streams). SkulMaster stores all records locally in an encrypted skulmaster.sys database protected against tampering.

  • ✓ Automated Master Broadsheet: Computes Test 1, Test 2, Subject Means, Ordinal Subject Ranks, and Final Class Positions automatically.
  • ✓ Bursar Fee Ledger & PIN Protection: Track termly expected fees, payments, and balances in Leones (Le) with dedicated Finance PIN security.
  • ✓ Cascading Data Integrity: Transactional safeguards for student subjects, attendance logs, and historical academic years.
